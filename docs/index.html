Architecture & Blast Shield Specification

v1.0 Spec

Deterministic 5-Stage Pipeline (<15ms)

  1. Intent Categorization (0–35 pts): Regex heuristics detect UI edits (4pts) vs Concurrency/Lock triage (35pts).
  2. DFS Import Fan-Out (0–30 pts): Scans package imports to assess blast radius (1 leaf file vs core contracts).
  3. Structural AST Depth (0–20 pts): Evaluates branch complexity, async flow, and transaction blocks.
  4. Empirical Revert Risk (0–15 pts): Queries SQLite git telemetry to flag files with ≥20% revert rates.
  5. Route & Blast Cap Dispatch: Recommends model, effort level, and prompt token budget limits.
